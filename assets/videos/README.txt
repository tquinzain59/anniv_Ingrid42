# 🎥 Dossier Vidéos d'Ingrid

Pour afficher automatiquement votre vidéo d'Ingrid en arrière-plan en boucle avec le filtre cinématique sombre :

1. Déposez votre vidéo dans ce dossier sous le nom :
   `background.mp4`
   *(ex: `/assets/videos/background.mp4`)*

2. La page web la chargera automatiquement en boucle silencieuse (`autoplay muted loop playsinline`) avec le filtre cinématique sombre en surimpression.

> **Astuce :** Vous pouvez aussi glisser-déposer n'importe quel fichier vidéo (.mp4, .mov, etc.) directement sur la page web ouverte dans votre navigateur, ou cliquer sur le bouton **« 📁 Importer vos vidéos »** en bas à gauche de la page !
